## 更新规则

1. 发现新问题时，先加一行到表格
2. 修复后更新状态和证据
3. 涉及效果的优化，必须在同一份评测集上跑前后对比
4. 面试可讲的问题，同时整理到桌面 `求职/RAG项目问题与面试素材.md`
