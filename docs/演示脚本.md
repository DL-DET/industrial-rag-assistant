# 演示脚本（60 秒）

录制前先读这一页，照着操作即可，不需要背稿。

## 录制前准备

1. 启动应用：`streamlit run app.py`
2. 确认知识库里有 2 份资料（`docs/ui-preview.png` 里那份列表状态即可）
3. 浏览器窗口宽度调到 1440，缩放 100%
4. 关闭无关标签页
5. 录屏工具：Windows 用 `Win + G`，或 OBS Studio

## 录制流程

### 0:00 – 0:08　首页

**动作**：停在首页，不动。

**口播**：

> 这是一个工业设备知识库 RAG 应用。左边是智能问答，右边是知识库更新。
> 设备手册先解析、清洗、切块，再写入本地向量库。

### 0:08 – 0:28　检索与引用

**动作**：

1. 输入：`DTII-800 带式输送机的带速和输送能力是多少？`
2. 等答案流式输出完
3. 鼠标移到引用位置（`[资料 1：…]` 或"引用文件"那一行）
4. 展开下面的"引证资料"

**口播**：

> 问题先向量召回 10 条，再用 qwen3.7 重排取前 3 条。
> 答案是流式返回的，引用会自动补上文件名，下面的引证卡片能看到具体来自哪个文件。

### 0:28 – 0:33　Trace

**动作**：鼠标移到 `TRACE #` 和耗时那几行。

**口播**：

> 每次查询都有 trace，记录检索、重排、生成的耗时和候选数，方便定位瓶颈。

### 0:33 – 0:48　拒答

**动作**：

1. 输入：`如何办理特种设备使用登记证？`
2. 等拒答出现
3. 鼠标移到"依据不足，已跳过生成"和下面那行分数

**口播**：

> 这是一个知识库里没有的问题。重排分只有 0.15，低于 0.75 的阈值，
> 系统直接拒答，不调用大模型，省掉大约 6 秒。
> test 集上拒答精确率 100%，召回率 91.7%。

### 0:48 – 0:56　知识库管理

**动作**：

1. 点左侧"知识库更新"
2. 展开"已入库资料"
3. 鼠标停在版本号和更新时间上

**口播**：

> 资料入库带版本号和 doc_id，重新上传同一份文件会自动替换旧版本，也可以手动删除。

### 0:56 – 1:00　收尾

**动作**：停在资料列表，鼠标不动。

**口播**：

> 100 条评测集上 recall@1 是 0.987，MRR 0.993。代码和评测报告都在 GitHub。

## 录制注意事项

- **不要把鼠标乱晃**，停在正在讲的位置
- **拒答那一题不要换成 `ABB ACS880`**。它是评测集里的 u09，分数 0.846，属于真实分数重叠，
  拒不掉，会当场翻车。用 `如何办理特种设备使用登记证？`，分数稳定在 0.15 左右
- 如果第一次跑的答案引用了编号但没补全，重跑一次即可，模型输出有波动
- 录完检查：末尾是否露出个人信息、是否有报错提示
